# NEUROFIT v0.9

Mobile-first fitness app prototype built with Next.js, React, Tailwind CSS v4 and localStorage.

## What's new in v0.9
- One dedicated looping MP4 demonstration for every exercise in the built-in exercise library.
- Training screen redesigned for one-handed mobile use.
- Exercise guidance is specific to each exercise.
- Exercise detail opens as a mobile bottom sheet.
- Exercise library uses the corresponding video instead of reusing one static image.
- Rest timer remains accessible while training.

## Exercise videos
The included MP4s are original lightweight instructional animations generated for this prototype. They are not third-party footage and are not intended to replace professional instruction.

Videos:
- `/public/exercises/videos/supino.mp4`
- `/public/exercises/videos/agachamento.mp4`
- `/public/exercises/videos/puxada.mp4`
- `/public/exercises/videos/remada.mp4`
- `/public/exercises/videos/rosca.mp4`
- `/public/exercises/videos/triceps.mp4`

## Run
```bash
npm install
npm run dev
```

Open `http://localhost:3000`.
